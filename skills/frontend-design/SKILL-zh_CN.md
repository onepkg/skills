此技能指导创建避免通用"AI slop"美学的独特、生产级前端界面。以非凡的关注度实现真正的工作代码，注重美学细节和创意选择。

用户提供前端需求：要构建的组件、页面、应用程序或界面。他们可能包括关于目的、受众或技术约束的上下文。

## 设计思维

在编码之前，理解上下文并致力于一个大胆的美学方向：
- **目的**：此界面解决什么问题？谁使用它？
- **基调**：选择一个极端：极简主义、最大化混乱、复古未来主义、有机/自然、奢华/精致、 playful/toy-like、editorial/magazine、brutalist/raw、art deco/geometric、soft/pastel、industrial/utilitarian 等。有太多口味可供选择。使用这些作为灵感，但设计一个真正符合美学方向的作品。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：什么使这个令人难忘？人们会记住的一件事是什么？

**关键**：选择一个清晰的概念方向并精确执行它。大胆的最大主义和精致的极简主义都有效 - 关键是意向性，而不是强度。

然后实现工作代码（HTML/CSS/JS、React、Vue 等）：
- 生产级且功能完整
- 视觉上引人注目且令人难忘
- 与清晰的美学观点 cohesive
- 在每个细节上都 meticulously refined

## 前端美学指南

专注于：
- **字体排版**：选择美观、独特、有趣的字体。避免通用字体如 Arial 和 Inter；选择提升前端美学的独特选择；意想不到的、有个性的字体选择。将独特的展示字体与精致的正文字体配对。
- **颜色和主题**：致力于 cohesive 美学。使用 CSS 变量保持一致性。主导颜色配合锐利的强调色胜过 timid、均匀分布的调色板。
- **动画**：使用动画进行效果和微交互。优先使用纯 CSS 解决方案用于 HTML。如果可用，为 React 使用 Motion 库。专注于高影响力时刻：一个精心编排的页面加载，带有错开的揭示（animation-delay）比分散的微交互创造更多的愉悦。使用 scroll-triggering 和令人惊喜的悬停状态。
- **空间构图**：意外的布局。不对称。重叠。对角线流动。打破网格的元素。慷慨的负空间或受控密度。
- **背景和视觉细节**：创造氛围和深度，而不是默认为纯色。添加匹配整体美学的上下文效果和纹理。应用创意形式，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰边框、自定义光标和颗粒叠加。

切勿使用通用的 AI 生成美学，如过度使用的字体家族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（特别是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏上下文特定个性的 cookie-cutter 设计。

创造性地解释并做出感觉真正为上下文设计的意外选择。没有设计应该相同。在明暗主题、不同字体、不同美学之间变化。永远不要收敛于常见的选择（例如 Space Grotesk）跨代。

**重要**：将实现复杂性与美学愿景匹配。最大主义设计需要广泛的代码，带有大量的动画和效果。极简主义或精致的设计需要克制、精度和对间距、字体排印和微妙细节的仔细关注。优雅来自很好地执行愿景。
