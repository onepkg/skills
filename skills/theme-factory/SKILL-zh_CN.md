# 主题工厂技能

此技能提供经过策划的专业字体和颜色主题集合，每个主题都有精心选择的调色板和字体配对。一旦选择主题，就可以将其应用于任何制品。

## 目的

要为演示幻灯片组应用一致、专业的样式，请使用此技能。每个主题包括：
- 带有十六进制代码的内聚调色板
- 标题和正文文本的互补字体配对
- 适合不同上下文和受众的独特视觉标识

## 使用说明

要将样式应用于幻灯片组或其他制品：

1. **显示主题展示**：显示 `theme-showcase.pdf` 文件以让用户直观地看到所有可用主题。不要对其进行任何修改；只需显示文件供查看。
2. **询问他们的选择**：询问要应用于组的主题
3. **等待选择**：获得对所选主题的明确确认
4. **应用主题**：一旦选择了主题，就将所选主题的颜色和字体应用于组/制品

## 可用主题

以下是可用的 10 个主题，每个主题都在 `theme-showcase.pdf` 中展示：

1. **Ocean Depths** - 专业且舒缓的海洋主题
2. **Sunset Boulevard** - 温暖且充满活力的日落颜色
3. **Forest Canopy** - 自然且接地的土色调
4. **Modern Minimalist** - 干净且当代的灰度
5. **Golden Hour** - 丰富且温暖的秋季调色板
6. **Arctic Frost** - 凉爽且清脆的冬季灵感主题
7. **Desert Rose** - 柔和且精致的尘土色调
8. **Tech Innovation** - 大胆且现代的科技美学
9. **Botanical Garden** - 新鲜且有机的花园颜色
10. **Midnight Galaxy** - 戏剧性且宇宙般的深色调

## 主题详情

每个主题在 `themes/` 目录中定义，具有完整规范，包括：
- 带有十六进制代码的内聚调色板
- 标题和正文文本的互补字体配对
- 适合不同上下文和受众的独特视觉标识

## 应用流程

选择首选主题后：
1. 从 `themes/` 目录读取相应的主题文件
2. 在整个组中一致地应用指定的颜色和字体
3. 确保适当的对比度和可读性
4. 在所有幻灯片上保持主题的视觉标识

## 创建您自己的主题

要处理现有主题都不适用于制品的情况，请创建自定义主题。根据提供的输入，生成与上述类似的新主题。给主题一个类似的名称，描述字体/颜色组合代表什么。使用提供的任何基本描述来选择适当的颜色/字体。生成主题后，显示它以进行审查和验证。之后，如上所述应用主题。
